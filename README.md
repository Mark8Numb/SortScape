# ✨ SortScape v1.3

**Умный анализатор файлов + сортировка + извлечение данных в Obsidian, Telegram и Excel**

[![Лицензия: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![PWA Ready](https://img.shields.io/badge/PWA-Ready-blueviolet)](https://web.dev/progressive-web-apps/)

SortScape — это полностью локальное PWA для работы с папками. Оно позволяет:
- Просматривать файлы (изображения, видео, аудио, текст) прямо в браузере.
- Сортировать тысячи файлов по категориям (изображения, видео, аудио, документы, архивы).
- Извлекать **важную информацию** из любого файла:
  - из скриншотов – распознавание текста (OCR), QR‑кодов, номеров заказов, сумм, дат, email, телефонов;
  - из видео/аудио – длительность, разрешение;
  - из текстовых файлов – поиск тех же паттернов.
- Экспортировать извлечённые данные в:
  - 📝 **Obsidian** (отдельные `.md` заметки с frontmatter);
  - 📋 **Telegram** (копирование форматированного сообщения);
  - 📊 **Excel** (таблица для массовой обработки скриншотов);
  - 📚 **один общий MD‑файл** для всех файлов сразу.

**Всё работает локально, ваши файлы НИКУДА не отправляются.**

## 🚀 Возможности

| Функция | Описание |
|---------|----------|
| 📁 Загрузка папок | Рекурсивный обход, сохранение структуры |
| 🖼️ Превью | Миниатюры изображений, встроенные плееры для видео/аудио |
| 🧠 Извлечение данных | OCR (русский+английский), QR‑коды, поиск паттернов |
| 🏷️ Сортировка | Группировка по типам (изображения, видео, аудио, документы, архивы) |
| 📝 Экспорт в Obsidian | `.md` с YAML фронтмэттером, готово для заметок |
| 📋 Копирование в Telegram | Форматированное сообщение с эмодзи |
| 📎 Экспорт в Excel | Подходит для анализа скриншотов |
| 📚 Массовое извлечение | Обработка всех файлов → один MD‑файл |
| ⏸️ Остановка процесса | Индикатор прогресса, кнопка прерывания |
| 🌐 PWA | Можно установить на рабочий стол, офлайн после первого запуска |

## 📦 Установка и запуск

### Способ 1 – просто открыть файл
1. Скачайте `index.html`.
2. Дважды кликните – откроется в браузере.
3. Рекомендуется использовать **Chrome** или **Edge** (лучшая поддержка PWA).
